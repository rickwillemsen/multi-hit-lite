Multi-hit gene combinations

Identifies multi-hit combinations, using a greedy heuristic. It selects a set of gene combinations that together cover as many tumor samples as possible, while covering as few normal samples as possible. Everything runs in this browser tab: your files are never uploaded.

References

  • This tool is based on: arXiv:2610.09420
  • A more advanced method, which requires optimization solvers (CPLEX or Google OR-Tools), was introduced at CP 2026: 10.4230/LIPIcs.CP.2026.57. Its implementation is publicly available at github.com/rickwillemsen/MHCDSCP.

OffOnStep-by-step visualization

Shows how the method works on a small dataset, step by step. Turning this on resets all settings to a small example (8 genes, 7 tumor and 4 normal samples, 6 candidate gene combinations); turning it off restores the normal defaults. You can still change the settings or upload your own data, but the visualization is only readable for small datasets (up to about 15 genes and 20 samples per class).

Settings reset to the small example. Click Generate data below to start.

1 Data

Makes a random normal and tumor file with a few planted gene combinations that occur mostly in tumor samples, so you can see whether the heuristic finds them.

Required file format

Two CSV files, one with normal samples and one with tumor samples, in this format:

3,5
0,ENSG00000141510,0,1,0,0,1
1,ENSG00000171862,1,1,0,0,0
2,ENSG00000157764,0,0,0,1,0
  • Line 1: number of genes, number of samples.
  • Then one line per gene: row number (0, 1, 2, …), gene ID, then a 0 or 1 for every sample (1 = mutated).
  • Both files must list the same genes in the same order; the number of samples may differ.

Exclusion list optional

Genes on this list are left out of the analysis. Use a text or CSV file with one gene ID per line, written exactly as in the data files (if a line has several columns, the first is used; lines starting with # are skipped).

2 Settings

With the same data and settings, including the random seed, every run gives the same result.
